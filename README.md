# NFL Big Data Bowl: herramienta para el comentarista

Es una página web que le ahorra horas de preparación al comentarista de la NFL y le da con qué hablar al aire. Cada semana le presenta la jugada, el partido, el jugador y el equipo destacados, junto con puntos listos para comentar. Con ella, el comentarista llega al micrófono con datos claros y sin buscarlos a mano.
